# pizero-tv suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single display host (`tvd`) + shared kit (`tvkit`) + CLI (`bin/tv`) for the Pi Zero TV, and all 12 Gemini modules plus sfdispatch rebuilt on it with real data and the new visual language.

**Architecture:** One long-running pygame process owns a 1280×720 `SCALED` window and runs modules as in-process plugins (`tvkit.Module`), composing each module's static layer once per data change and animating on top at adaptive FPS. Data comes from `tvkit.Source` fetch threads with on-disk last-good caches. `bin/tv` talks to the host over a unix socket, locally or via `ssh <host>`.

**Tech Stack:** Python 3.13, pygame 2.6.1, numpy (trippy), psutil (syshud), requests, tomllib; pytest on the Mac (`.venv`); fontTools (dev only).

**Spec:** `docs/superpowers/specs/2026-11-23-suite-design.md`

## Global Constraints
- Real data only; on failure show waiting/stale/offline, never placeholders.
- Logical surface 1280×720; window flags `FULLSCREEN | SCALED | DOUBLEBUF` (dev: env `TV_WINDOWED=1` drops FULLSCREEN).
- Palette exactly: ground `#0C1F24`, tide `#133038`, bone `#EEE6D3`, lichen `#86A3A0`, sodium `#FFA630`, coral `#FF5A5F`, seaglass `#6FD6C5`; module keys: weather sodium, finance seaglass, crypto `#F7C948`, threatmap coral, space `#A88BFF`, flights sodium, news `#7FB2FF`, syshud seaglass, lanradar `#8FE36B`, sfdispatch coral.
- Fonts only from `tvkit/fonts/`: Big Shoulders Display 800/600/400, IBM Plex Sans Condensed 400/500/600, IBM Plex Mono 400/500, katakana subset. Min text size 14 px. Sentence case except the spine. No emoji.
- Every string drawn through `tvkit.text.draw(..., max_w=...)` (ellipsis fit).
- Content area x 190–1250; spine x 0–150 with a `tide` hairline at x=150.
- Footer bottom-right: status dot + `live` / `stale 12m` / `offline` + `legitbiz.research`.
- Splash text: `legitbiz.research`, incoming module title + blurb, `github.com/NPCmillionaire/pizero-tv`; held ≥ 1.2 s and until `ready` or 8 s.
- Poll ≥ 60 s per public API; NASA NeoWs ≤ 1/hour; CoinGecko ≤ 3 calls/min total.
- No personal data in the repo (location only in `~/.config/pizero-tv/config.toml` on the Pi); no lanradar/syshud screenshots committed.
- Steady-state target per module on the Pi: ≤ 35% of one core, ≤ 70 MB RSS.
- Dev env: `.venv` from the sfdispatch plan plus `uv pip install fonttools numpy psutil`.

## Review Focus
1. Module raises in `start/update/draw_static/draw_live` → host shows the crash scene for 10 s and moves on; host never dies. (Task 3 `test_module_crash_shows_error_scene_then_continues`.)
2. Switching modules 500× in cycle mode leaks no threads and no memory growth beyond noise. (Task 3 `test_switch_stops_previous_sources` asserts every `Source` thread of the old module has exited.)
3. Host restart with persisted state pointing at a module that no longer exists → falls back to the default cycle, no crash. (Task 3 `test_state_unknown_module_falls_back`.)
4. Config missing / missing `[place]` → location modules render "Set [place] in ~/.config/pizero-tv/config.toml", no crash. (Tasks 6, 10 `test_render_without_place`.)
5. Endpoint returns HTML/empty/garbage → source marks offline (or stale if cached), never raises into the module. (Task 2 `test_source_bad_payload_keeps_last_good`.)

### Task 2: tvkit data — Source, cache, config

**Files:** Create `tvkit/source.py`, `tvkit/config.py`, `config.example.toml`, `tests/tvkit/test_source.py`, `tests/tvkit/test_config.py`.

**Interfaces — Produces:**
- `Source(name: str, fetch: Callable[[], Any], interval: float, parse: Callable[[Any], Any] = identity, cache_dir: str | None, clock=time.monotonic, wall=time.time)`: `.start()` / `.stop()` (thread, `threading.Event`), `.poll_once()` (sync, for tests), `.value` (parsed last good or None), `.status` ∈ `{"waiting","live","stale","offline"}`, `.age_s` (seconds since last good, wall clock), `.version: int` (increments on new value). Parse/fetch exceptions never escape. Last good raw payload is written to `<cache_dir>/<name>.json`; on construction a cached payload loads with status `stale`. `stale` when age > `3 × interval`.
- `config.load(path=None) -> Config` (`~/.config/pizero-tv/config.toml` default; missing file → defaults) with `.place: Place | None` (`name, lat, lon, timezone`), `.units_temp` (`"F"`), `.lan_subnet: str | None`, `.cycle_seconds` (90), `.cycle_modules: list[str] | None`.

- [ ] **Step 1: Failing tests** — `test_source_live_after_poll`, `test_source_bad_payload_keeps_last_good` (fetch returns `"<html>"`, parse raises → value unchanged, status `stale` if value else `offline`), `test_source_fetch_raises_offline`, `test_source_cache_roundtrip` (tmp_path: poll → new Source sees value with status `stale`), `test_source_stale_after_3_intervals`, `test_source_stop_joins_thread`, `test_config_missing_file_defaults`, `test_config_reads_place`.
- [ ] **Step 2–4:** FAIL → implement → PASS. **Step 5:** commit `feat(tvkit): Source with disk cache; config`.

### Task 3: Module API + display host

**Files:** Create `tvkit/module.py`, `tvkit/host.py`, `tvkit/scenes.py` (splash, crash, standby), `tvkit/registry.py`, `tvkit/control.py` (socket server + client), `tests/tvkit/test_host.py`, `tests/tvkit/test_registry.py`, `tests/tvkit/test_control.py`.

**Interfaces — Produces:**
- `Module`: class attrs `name, title, blurb, key, aliases=()`; methods `start(ctx: Ctx)`, `stop()`, `ready -> bool` (default: all `self.sources` non-waiting), `update(now: float) -> bool`, `draw_static(surf)`, `draw_live(surf, t) -> bool` (True = still animating → host uses 24 FPS, else 8), `key(event)`, `status() -> tuple[str, float|None]` (worst of its sources), helper `self.source(...)` that registers a `Source` with the module's cache dir and starts it.
- `Ctx(config: Config, cache_dir: str, w: int, h: int)`.
- `registry.discover(root="modules") -> dict[str, type[Module]]` (key = `name` and each alias).
- `Host(screen, registry, config, state_path, clock=time.monotonic)`: `.show(name)`, `.next()`, `.cycle(seconds, names)`, `.standby()`, `.step()` (one frame: handles splash hold, ready wait, error scene, cycle timer, static rebuild, live draw), `.status() -> dict`. Exceptions from a module are caught in `step`, logged, crash scene shown for 10 s, then `next()` (cycle) or standby.
- `control.serve(host, path)` (non-blocking socket accept polled in `step`), `control.send(path, line) -> str`. Protocol lines: `show <name>`, `next`, `cycle <sec> [names…]`, `stop`, `status`, `screenshot <path>`, `reload`.
- `tvkit/__main__.py`: `python -m tvkit` runs the host (window per Global Constraints, socket at `$XDG_RUNTIME_DIR/pizero-tv.sock`, state `~/.local/state/pizero-tv/state.json`); `python -m tvkit --only <name>` runs one module without socket (dev).

- [ ] **Step 2–4:** FAIL → implement → PASS. **Step 5:** commit `feat(tvkit): module API, display host, splash, control socket`.

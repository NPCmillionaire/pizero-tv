# Channels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** TV channel feel (numbers, static, OSD, guide, remote commands) and video channels (Computerphile, Shorts, config-defined) for pizero-tv.

**Architecture:** The host gains a channel list (registry order → numbers, guide at 00), a 0.4 s `static` phase and a 3 s OSD overlay, and stops waiting on `ready`. A `video` package exports several `VideoChannel` modules that run mpv as an external fullscreen player; the host idles while `module.external` is true.

**Tech Stack:** existing tvkit; mpv 0.40 (apt), yt-dlp (standalone, current).

**Spec:** `docs/superpowers/specs/2026-11-24-channels-design.md`

## Global Constraints
- Channel N = index in `registry.channels()` (guide first as 00). OSD text exactly `CH {n:02d}  {TITLE}`, green `#7CFF6B` on translucent black, top-right, visible 3 s then fades over 0.5 s.
- Static phase 0.4 s; module `start()` runs at the beginning of static (data fetch overlaps the static).
- Two-digit entry window 1.2 s.
- Video: mpv args include `--fs --hwdec=auto-safe --ytdl-format=bv*[height<=720][vcodec^=avc1]+ba/b[height<=720]` and `--osd-playing-msg=CH nn  TITLE`; listing cache 6 h at `<cache_dir>/listing.json`.
- Host draws nothing and returns 2 FPS while `current.external` is true.

## Review Focus
1. mpv missing or yt-dlp failing → channel shows a clear message, no crash, no orphaned processes. (`test_video_without_mpv_shows_message`)
2. Switching away from a video channel kills mpv (and its yt-dlp child). (`test_stop_kills_player`)
3. `tv up` from the last channel wraps to 00; `tv down` from 00 wraps to last. (`test_up_down_wrap`)
4. Typing `1` then `2` within 1.2 s goes to 12, not 1 then 2. (`test_two_digit_entry`)
5. A crash during the static phase is contained like any module crash. (existing crash tests, updated)
